# 端對端測試

用真的瀏覽器走一次顧客最重要的流程：挑卡、加入購物車、結帳、模擬付款，最後確認結果頁顯示「付款成功」，並檢查訂單已付款、庫存有扣。

## 怎麼跑

1. 先啟動後端（要接得到資料庫）：`cd backend && ./mvnw spring-boot:run`
2. 第一次要安裝：`cd e2e && npm install && npm run browser`
3. 執行：`npm test`（官網會自動啟動，已經開著就直接沿用）

## 設定

| 環境變數 | 預設值 | 用途 |
|---|---|---|
| `E2E_DB_URL` | `postgres://argo:1234@127.0.0.1:5432/argo` | 測試用來建資料與檢查結果的資料庫 |
| `E2E_BASE_URL` | `http://localhost:5173` | 指定後就不會自動啟動官網 |

## 資料

測試開始時自己建一個系列和一張卡（編號以 `E2E` 開頭、庫存 3），結束後連同測試訂單一併刪除，不會動到現有資料。

## 在 GitHub 上跑

到 Actions 的 CI 頁面按「Run workflow」。目前只能手動觸發，穩定後再掛到每個 PR。
