# Argo

傳說中尋找金羊毛的船，象徵尋寶之旅。

## 為什麼會做這個專案

從小就很喜歡集換式卡牌遊戲。有人拿它來對戰、交朋友，也有人只是單純喜歡收藏。不管是哪一種，我都覺得每一張卡都很珍貴，裡面有很多回憶。所以把專案取名叫「尋寶的船」，希望大家來到這個網站，都能找到自己心愛的那一張卡。

## 這個網站能做什麼

**給顧客（官網）**
- 逛卡片：可以用名字、系列、顏色、稀有度等條件找卡，也可以只看有現貨的。
- 看卡片詳情：售價、參考市價、庫存、卡片效果。
- 中英文切換：卡名和效果都有繁體中文。
- 買東西：放進購物車、填寫收件資料、下單、付款。未付款的訂單會保留 30 分鐘，超時自動取消並把庫存還回去。
- 會員：可以用 Email 和密碼註冊、登入。登入後下的訂單會記在「我的帳號」裡，結帳時姓名和 Email 也會自動帶入。
- 不想註冊也可以：結帳時直接以訪客身分購買，不需要任何帳號。
- 查訂單：不用註冊，輸入訂單編號和下單時的 Email 就能查。
- 特價標示：有額外折扣的卡片，會用刪除線劃掉原價，旁邊顯示紅色的 SALE!!。

目前付款是模擬的，不會真的扣款。

**給工作人員（兩個後台）**
- 業務後台：
  - 調整每張卡的額外折扣，也可以依系列篩選卡片。
  - 管理卡牌系列：可以把整個系列下架或重新上架，也可以一次替整個系列設定同一個折扣。
  - 系列下架後，官網仍然看得到這個系列和它的卡片，但會標示「已下架」，顧客不能購買。
- 運維後台：查看稽核紀錄，也就是誰、什麼時候、做了什麼事。
- 後台不開放註冊，帳號由管理者手動建立，每個帳號有自己的角色（最高權限、一般管理員、客服、運維）。
- 每個人登入後，左邊的選單只會看到自己有權限的功能。
- 工作人員的重要操作都會被記下來，出問題時可以追查是誰做的。

## 價錢怎麼算

- 售價 ＝ 原版美金市價 × 0.9 × 額外折扣。
- 額外折扣預設是 1（沒有折扣），工作人員可以改成例如 0.4（四折）。
- 如果某張卡被人工指定了價格，就不再套用折扣。

## 卡片資料從哪裡來

- 英文名稱和價格：optcgapi.com
- 繁體中文名稱和效果：Bandai 官方繁中卡表

資料每天凌晨會自動更新一次。卡片內容的版權屬於原權利人，正式營運前請自行確認使用條款。

## 專案長什麼樣子

```
Argo/
├── backend/             後端（處理資料和規則）
└── frontend/
    ├── official-site/   官網（顧客看的）
    ├── admin/           業務後台
    └── ops/             運維後台
```

使用的主要技術：Java、Spring Boot、PostgreSQL、Vue。

## 怎麼在自己的電腦上跑起來

1. 準備好 PostgreSQL，建立名為 `argo` 的資料庫。
2. 啟動後端：進入 `backend` 資料夾，執行 `./mvnw spring-boot:run`。
3. 啟動官網：進入 `frontend/official-site`，執行 `npm install` 再執行 `npm run dev`。
4. 後台同理，分別在 `frontend/admin`、`frontend/ops` 執行同樣的指令。
